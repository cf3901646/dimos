# Tolerate measured feedback near joint limits without relaxing commands

Streaming Pink control treats nominal model limits as the command authority while accepting measured hardware state up to a configurable feedback tolerance beyond those limits. Accepted feedback is normalized directly to an inward command margin before solving; generated commands are saturated to that same inward band and then checked by the existing per-tick joint-delta guard. Feedback beyond tolerance drops the tick without disengaging teleoperation, and Pink's `safety_break` remains enabled. This policy applies only to bounded Pink-controlled joints in the streaming frame-target step—not continuous joints, additional outputs such as grippers, or iterative planning—so encoder error cannot deadlock control and cannot expand the robot's commanded range.
